3. End-to-End Encryption (Core Feature)

        Instead of sending plain text:

        Hello

        Send:

        P8k29Asd872KJH...

        Only the intended recipient can decrypt it.

4. RSA Key Pair

        Each user gets:

        Public Key

        Private Key

        Public keys are shared.

        Private keys remain secret.

        AES session keys are encrypted using RSA before being exchanged.

5. AES Encryption

        Actual chat messages are encrypted using AES-256 because it's much faster than RSA for large amounts of data.

        Message

        ↓

        AES

        ↓

        Ciphertext

6. Digital Signature

        Each message is signed.

        Receiver verifies:

        ✔ Message wasn't modified.

        ✔ Sender is authentic.
